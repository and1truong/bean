# Goal: Bean v0.12 Generated Semantic and Rule Tests

Status: complete

Bean v0.12 generates deterministic checks from compiler-validated AppIR, explicit TestSuite expectations, and DemoSeed records. Generated runtime cases remain ordinary TestSuite definitions and execute through the v0.11 isolated runner; structural and HTTP journey checks report stable source-traced evidence.

## Completed contract

- Explicit Rule and Action suites produce replay evidence while retaining their declared expectations as the business oracle.
- Policy-denial and invalid-Lifecycle cases run through Actions only where metadata proves the negative; representative CRUD writes use Actions and verification reads use Views.
- DemoSeed-backed CRUD generation requires relation-complete typed values and omits cases it cannot honestly construct.
- Schema, Rule, Policy, Lifecycle, route, and eligible anonymous HTTP journeys carry stable ordered identities and deterministic evidence.
- Generated definitions share the explicit suite bounds, immutable AppIR compilation, isolated SQLite runtime, and safe assertion diagnostics.
- Generation does not infer business requirements, bypass authorization, or add provider/network/script capabilities.
